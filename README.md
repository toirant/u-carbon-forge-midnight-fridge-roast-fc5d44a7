One-line entry for the [Midnight Fridge Roast](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun: a program that writes a single roast of a smart fridge that refuses to open after midnight to `/output/entry.txt`.

## Entry

> My fridge locks at midnight like a bouncer — buddy, it's leftover pizza, not a nightclub.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`, reads it back, and verifies the gate: UTF-8 text, 1–200 characters, a single line, not only whitespace.
